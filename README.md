# ExamForm Pro - منصة الاختبارات الذكية 📝🛡️

تطبيق أندرويد متكامل لإدارة وإنشاء وتقديم الامتحانات والنماذج الإلكترونية على غرار **Google Forms**، مزود بحماية فائقة ضد الغش، تصدير فوري إلى Microsoft Excel، ودعم كامل لتخطي إعدادات Google Console للعمل المباشر.

---

## 📱 تحميل ملف التطبيق (APK Download)

ملف التطبيق جاهز ومرفق مباشرة داخل مستودع المشروع:

- 📥 **تحميل مباشر من المسار:** [`/apk/ExamFormPro.apk`](apk/ExamFormPro.apk)
- 📥 **أو من المجلد الرئيسي:** [`/ExamFormPro.apk`](ExamFormPro.apk)

يمكنك تنزيله مباشرة على هاتفك أو جهازك الأندرويد وتثبيته فوراً.

---

## ✨ المميزات الرئيسية

### 1. 🛡️ حماية متقدمة ضد الغش وتصوير الشاشة
- تفعيل عتادي لخاصية `WindowManager.LayoutParams.FLAG_SECURE` لمنع التقاط لقطات الشاشة (Screenshots) أو تسجيل الفيديو أو عرض المحتوى في قائمة التطبيقات السابقة.
- منع نسخ وتحديد الأسئلة والخيارات داخل الامتحان.
- مراقبة وتتبع مغادرة التطبيق وتسجيل عدد المخالفات في لوحة المعلم فورياً.

### 2. 📝 قوالب أسئلة متعددة وقيم الدرجات
- اختيار من متعدد (Multiple Choice).
- مربعات اختيار متعددة (Checkboxes).
- صح أو خطأ (True / False).
- إجابة قصيرة (Short Answer).
- تقييم بالنجوم (Rating).
- تحديد قيمة الدرجات لكل سؤال بشكل منفصل مع تصحيح وحساب تلقائي للنسبة المئوية.

### 3. 📊 تصدير فوري إلى Excel (.xlsx) و CSV
- توليد مصنف Microsoft Excel أصلي بصيغة `.xlsx` مباشرة عبر `FirestoreQuizExcelHelper`.
- دعم التصدير بصيغة CSV مع ترميز `UTF-8 BOM` لضمان قراءة النصوص والأسماء العربية بدقة دون تشوه.
- مشاركة فورية عبر شريط المشاركة في أندرويد إلى Excel أو البريد الإلكتروني أو واتساب.

### 4. 🎨 تخصيص هوية التطبيق والشعار
- تغيير اسم التطبيق واسم المؤسسة التعليمية أو المعلم.
- اختيار الشعار والأيقونة المناسبة (درع أمان، قبعة تخرج، صرح تعليمي، نجمة تميز).
- تغيير نظام ألوان التطبيق مع الحفظ التلقائي.

### 5. ⚡ تشغيل مباشر دون متطلبات Google Console
- التطبيق يعمل فوراً ودون الحاجة لتسجيل حسابات أو إعداد شاشات موافقة OAuth في Google Console.
- متوافق مع نظام أندرويد من الإصدار 7.0 (API 24) وحتى أحدث إصدارات Android 14/15/16.
