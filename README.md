# ExamForm Pro - منصة الاختبارات الذكية 📝🛡️

تطبيق أندرويد متكامل لإدارة وإنشاء وتقديم الامتحانات والنماذج الإلكترونية على غرار **Google Forms**، مزود بحماية فائقة ضد الغش، تصدير واستيراد فوري عبر Microsoft Excel، والربط السحابي المباشر أونلاين عبر Firebase Firestore.

## ✨ المميزات المضافة والجديدة

### 1. 📋 واجهة رئيسية مخصصة للامتحانات فقط
- تم تخصيص الواجهة الرئيسية لتقتصر **حصراً على بطاقات نماذج الامتحانات المتاحة** بدون أي لافتات أو إحصائيات مشتتة.
- مظهر عصري، مريح، وفاتح بالكامل (Light Theme) بألوان بيضاء وأرجوانية شبيهة بنماذج جوجل الأصلية.

### 2. 📊 رفع الامتحانات على البرنامج والداتابيز عن طريق Excel
- إمكانية استيراد نماذج الاختبارات كاملة من ملفات **Microsoft Excel (.xlsx)** و **CSV**.
- استخراج نصوص الأسئلة، نوع السؤال (اختيار من متعدد، صح أو خطأ، مربعات اختيار، إجابة قصيرة)، الخيارات، الإجابة الصحيحة، والدرجات تلقائياً.
- عند استيراد ملف الإكسيل يتم حفظ الامتحان في التطبيق ومزامنته ورفعه فورياً إلى قاعدة البيانات السحابية (Firestore).
- توفير ميزة "تحميل قالب فارغ" لمشاركة نموذج Excel جاهز للاستخدام.

### 3. ☁️ العمل أونلاين ورفع الامتحانات والنتائج سحابياً
- يعمل التطبيق بشكل أونلاين متصل بقاعدة بيانات **Firebase Firestore**.
- **رفع الامتحانات أونلاين:** أي نموذج يتم إنشاؤه أو استيراده يُرفع تلقائياً على مجموعة `exams` في Firestore ويتاح فورياً للطلاب.
- **رفع نتائج الطلاب أونلاين:** بمجرد إنهاء الطالب للامتحان، تُرفع إجابته ودرجته ونسبته المئوية وعدد مخالفات الشاشة تلقائياً على مجموعة `submissions` السحابية.
- لوحة تحكم المعلم تستقبل النتائج أونلاين مع إمكانية تحديث البيانات بضغطة زر وتصديرها إلى ملف Excel (.xlsx).

### 4. 🛡️ حماية متقدمة ضد تصوير الشاشة والنسخ (Anti-Cheating)
- تفعيل خاصية `WindowManager.LayoutParams.FLAG_SECURE` عتادياً لحجب تصوير الشاشة (Screenshots) وتسجيل الفيديو بالكامل.
- حظر تحديد ونقل نصوص الأسئلة.
- رصد وتتبع أي خروج أو تصغير للتطبيق واحتسابه كمحاولة غش تظهر في تقرير النتيجة.
